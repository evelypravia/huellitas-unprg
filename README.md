# TRAZO — Guía de sitios personales

Sitio editorial original, inspirado de forma general en el formato de un artículo de recursos, sin reproducir el diseño, contenido ni marca de Squarespace.

## Uso

Abre `index.html` en cualquier navegador. No requiere instalación ni servidor.

Las imágenes se cargan desde Unsplash y las tipografías desde Google Fonts, por lo que requieren conexión a Internet.
